## 4. App content declarations

### Target audience and content

- **Target age groups:** 18 and over only. Do **not** tick any under-18 band.
- **Appeals to children:** No.
- **Store presence for families:** Not enrolled in Designed for Families.

### Ads

- **Contains ads:** No third-party ad networks. Promoted placements are
  first-party paid listing positions purchased by sellers.

### In-app purchases

- **Yes.** Price range ₹200 – ₹1,000 (excluding GST).

### Data safety form

| Data type | Collected | Shared | Optional | Purpose |
| --- | --- | --- | --- | --- |
| Name | Yes | Yes (on your listing) | No | Account, seller identity |
| Email address | Yes | No | No | Account, support |
| Phone number | Yes | Yes, unless "Hide my phone number" is on | No | Buyer contact |
| Approximate location | Yes | Yes (city on listing) | Yes | Nearby search |
| Precise location | No | No | — | — |
| Photos and videos | Yes | Yes (on your listing) | Yes | Listing media |
| Voice or sound recordings | Yes | Yes (on your listing) | Yes | Optional seller voice note |
| Purchase history | Yes | No | No | Package billing |
| App interactions | Yes | No | No | Analytics, seller stats |
| Crash logs and diagnostics | Yes | No | No | Stability |
| Device or other IDs | Yes | No | No | Session and abuse prevention |

Additional answers:

- **Is all data encrypted in transit?** Yes (TLS).
- **Can users request data deletion?** Yes — in-app page plus privacy@motora.in.
- **Data deletion URL:** `https://motora-five.vercel.app/account-deletion`
- **Privacy policy URL:** `https://motora-five.vercel.app/privacy-policy`
- **Committed to the Play Families Policy?** Not applicable (18+).

### Permissions justification

| Permission | Why | Play declaration |
| --- | --- | --- |
| `INTERNET` | Load listings and media | Core functionality |
| `CAMERA` | Capture listing photos and walkaround video | Only on user action |
| `RECORD_AUDIO` | Optional seller voice note | Only on user action |
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` | Attach existing media to a listing | Only on user action |
| `ACCESS_COARSE_LOCATION` | Pre-fill city for nearby search | Optional; app works without it |

No sensitive permissions are requested: no background location, no contacts,
no SMS, no call log, no `QUERY_ALL_PACKAGES`, no `MANAGE_EXTERNAL_STORAGE`.

### Government apps / financial features

- Not a government app.
- Not a financial services app. The EMI calculator is an informational
  estimator only: it does not originate loans, quote lender offers, or process
  credit applications. On-road price and valuation figures are labelled
  estimates, not quotations.
